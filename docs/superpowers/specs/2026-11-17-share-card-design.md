# 赛后战报图（一键复制分享）设计

日期：2026-11-17
状态：已口头批准（内容引擎 + 先猜再揭晓 + 复制到剪贴板 + 打点）

## 目标

项目瓶颈在分发而不在留存（DAU/MAU ≈ 25%）。把赛后战报做成**玩家愿意主动发到开黑群 / 朋友圈的图**，
让复盘评分的深度（死亡归责、牵制换资源）自己出去传播；图角落带工具名作为唯一转化入口。

### 不做的事（V1）

- 不调 LLM 生成锐评：结算时等模型太慢，V1 用标签文案 + 事实引擎；锐评留给后续。
- 不出二维码：先用「GitHub / GitCode 搜 rank-analysis」文字，看打点再决定。
- 不做周报卡、「你 vs AI」争议卡（V2 / V3）。
- 不点名任何队友 / 对手：卡上只有本人。

## 谁最想分享

|---|---|---|
| 被连累 | 洗冤：「输了，但锅不在我」 | primary：直接展开 |

## 内容：一张卡只讲一个故事（`services/ai/review/shareFacts.ts`）

每类事实一个生成器，产出带「稀有度分」的候选；按标签口吻筛选（炫耀 / 洗冤 / 平常只要正面，自嘲只要负面），
第 1 条当标题、后 2 条支撑；「换个角度」在前 3 条间轮换标题。

| 事实 | 条件 | 例句 | 分数 |
|---|---|---|---|
| 牵制换资源 | 有 `traded` 阵亡 | 被 4 包 1 拖住，队友趁机拿到资源 | 3 + 0.3×次数 |
| 归责（正） | 阵亡 ≥3 且本人责任 ≤ 50% | 9 次阵亡，本人责任只算 4 次（依据：队友先崩 / 以少打多 / 被抓 / 团战中前两类） | 1 + 3×(1−占比) |
| 归责（负） | 阵亡 ≥5 且占比 ≥ 90% | 6 次阵亡，6 次算自己的 | 1 + 阵亡/5 |
| 反差 | KDA 队内名次与评分名次差 ≥2 | KDA 队内第 4，评分队内第 1 | 1.5 + 0.5×差 |
| 分项突出 | 分项「大幅领先 / 落后」 | 发育大幅领先同位置同英雄（依据取第一条数据） | 1.5 + … |
| 整体分位 | 前 / 后 20% 以内 | 本局表现约在同位置玩家前 5% | 1 + (25−x)/10 |

阈值 0.5（不是 0.6）：0.6 时回归局出现「10 次阵亡，本人责任只算 5.9 次」，「只」说不过去。

为此 `DeathView` 增加 `blame / enemies / allies / traded`（直接取 `AttributedDeath`，不重算）。

## 卡片（`components/gaming/ShareCard.vue`）

360×480 CSS 像素排版，导出 ×3 = 1080×1440（3:4，群聊 / 朋友圈不裁）。配色固定不跟主题。
三层：标签 + 一句人话 → 标题事实 + 支撑 → 分项等级条 + 时长 / LP / 隐藏分；底部工具名与「仅供参考」。

## 交互：先猜再揭晓（`PostGameReport.vue`）

```
结算 → 标注卡「你怎么看这局？」（可跳过）
     → 提交（或打开时已有标注）→ LabelCard 发 done → 揭晓战报图
     → 复制战报图 → 「已复制，去群里 Ctrl+V 粘贴」
```

- 标注保持「未受模型影响」，揭晓时情绪最高，顺手分享。
- 「跳过，直接看战报图」随时可点；无国服基准（无标注卡）的队列直接显示。
- 控制项只有：换个角度、隐藏名字。

## 导出与打点

- `modern-screenshot` 把卡片节点渲染成 PNG → `tauri-plugin-clipboard-manager.writeImage`（tauri 开 `image-png`）。
- 头像先 fetch 成 data URL 再画；asset 协议成功响应加 `Access-Control-Allow-Origin: *`（只是本地图标）。
- 打点：`track_share_card(action)` 白名单映射到 `track_feature`：`share_card_shown / copied / angle / self_roast`。
  Sentry Logs 按 feature 聚合即得分享漏斗（展示 → 复制）。
