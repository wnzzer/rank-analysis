# Champion library snapshots

This directory contains the normalized, versioned data used by the public champion library.
The desktop app embeds these JSON files at build time, so browsing champions, abilities,
level stats, patch changes, and matchup snapshots does not require the League client or a
runtime connection to OP.GG.

Refresh the snapshots from the repository root:

```bash
node scripts/champion-library/sync.mjs
```

The generator validates the catalog before replacing any file. Its current inputs are:

- Tencent's public League static data for Chinese names, descriptions, and media URLs.
- CommunityDragon character data for stat growth and attack-speed ratios.
- A build-time global aggregate for key matchup win rates and sample sizes.

Matchup files are intentionally marked `isPartial: true`: the current aggregate is a useful
counter overview, not a complete OP.GG clone or a China-server matchup matrix. Runtime UI must
preserve that label and render missing 15-minute metrics as unavailable. A future full matrix
should be generated by a permitted Match-v5 aggregation service and committed in the same
schema; it should never make every user's desktop scrape a third-party site.

Patch-note history is maintained separately under `data/patch-notes/archive`. New releases can
accumulate snapshots there, but the UI must not imply that missing older patches were archived.
