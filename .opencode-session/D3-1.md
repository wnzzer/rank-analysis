## Key Decisions
- CI 排查经验：**Frontend job 里 eslint 的 `any` warnings 会以 job annotations 出现但不会 fail**（npm run lint 无 max-warnings）；上一轮「Frontend 失败」误判实为 rustfmt 失败 + 我误看了 annotations
- rustfmt 细节：`let (a, b, c) = f();` 长度计算按 rustfmt 自己的宽度判定——97 字符不拆、99 字符要拆（`= ` 后换行缩进 8/4）；本机无 cargo fmt，判宽靠 CI 反馈
- 本环境测试坑（沿用）：裸 `nextTick()` 排不空外部 awaited mock 的 continuation——断言前用 `flushPromises()`；`vi.setSystemTime` 已装假时钟，`vi.useFakeTimers()` 抛错；mock stream 永远不 settle 时**不能 await generate**，只能 fire-and-forget + nextTick
- 组件测试坑（新增）：naive-ui stub Button 必须声明 `emits: ['click']`——否则父组件 `@click` 作为 attr 落到 stub 根元素 native listener 与 `$emit('click')` 双触发，generate 被调 2 次
- `GameDetail` 在 `lcu/api/game_detail.rs`（不在 match_history.rs）——测试 import 走 `crate::lcu::api::game_detail::GameDetail`
- 项目有本地 rustfmt.toml：max_width 100、Unix 换行
